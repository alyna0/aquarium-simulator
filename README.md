# aquarium-simulator
alyna.farm — Retro 90s Pixel-Art Aquarium Simulation

A retro-inspired pixel-art aquarium simulation built with Python and Pygame. Watch colorful fish swim, plants sway, and bubbles rise in a 90s-style aquarium environment.

Features

Retro 90s pixel-art graphics

Interactive aquarium with fish, plants, algae, driftwood, and bubbles

Animated water and plant swaying

Oxygen (O₂) and Carbon Dioxide (CO₂) gauges to monitor ecosystem balance

Buttons for interaction: Reset, Add Fish, Clear, Toggle Water, Sand, Stone, Wood, Algae, Grass, Daphnia, Bacteria

Scanline overlay for nostalgic CRT aesthetic
